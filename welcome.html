How to use it

1
Open Claude Code

Any folder works. The skills are global — they activate everywhere.

Tip: cd into a fresh folder for each new client so their assets stay isolated.

2
Type the intake command
/funnel-intake

Claude asks what you have. Paste anything you've got from your client:

📎 Their existing site URL · 📄 a PDF (discovery call notes, brand guide) · 📝 plain-text notes · all three at once is fine.

3
Watch the funnel build itself

About 5 minutes. Claude streams progress: market research, offer architecture, hooks, page copy (3,500+ words), 21 emails, VSL script, branded landing page, and AI-builder prompts for GoHighLevel / ClickFunnels / Framer.

When it's done, a dashboard opens automatically in your browser.

4
Take what you need

Every block in the dashboard has a copy button. Two of the most useful tabs:

📄 Page Copy

"Copy full page Markdown" at the top — paste straight into Webflow / Framer / Wordpress.

🎨 Design

Live preview of the branded HTML page + paste-ready prompts for GoHighLevel AI Studio, ClickFunnels AI, and Framer AI.

5
After the funnel is live, audit it
/audit

Once you have real metrics — ad CTR, page conversion, ROAS — type /audit. Claude asks for your live URL + numbers, fetches the actual page, compares against the assets, and tells you specifically what's underperforming and why.

The four slash commands

/funnel-intake

Build a complete client funnel from any input. Start here.

/audit

Post-launch data-driven audit. Paste live URL + metrics, get specific fixes.

/funnel-list

List all your client funnels with quick links to their dashboards.

/funnel-help

Quick reference inside Claude Code. Type this whenever you forget something.
