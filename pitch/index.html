What you actually type

Four commands.
That's the whole interface.

/audit After launch. Paste live URL + metrics. Get a diagnostic punch list with expected lifts.
/funnel-list All your client funnels in one list, with quick links to each dashboard.
/funnel-help Reference card right inside Claude Code, anytime you forget anything.

Install — under 60 seconds

No terminal. No npm. No symlinks.

    Have Claude Code installed

    Free at claude.com/claude-code.

  2. 2

    Open it in any folder

    New folder per client keeps assets isolated.

  3. 3

    Type two slash commands

    /plugin marketplace add naveends798/funnel-skills
/plugin install funnel-skills@funnel-skills
  4. 4

    Restart Claude Code

    It re-reads the plugin on launch.

  5. 5

    Type /funnel-intake
