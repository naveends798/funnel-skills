The solution

One plugin. Ten agents.
Wired together.

I got tired of building funnels by hand for clients, so I packaged the whole agency workflow as ten specialist Claude agents that hand off to each other — and shipped them as a one-command Claude Code plugin.

1 /plugin marketplace add naveends798/funnel-skills
2 /plugin install funnel-skills@funnel-skills
That's the entire install. Restart Claude Code. Done.
The ten agents

Each one is a specialist.
They hand off in sequence.

01

market-intelligence

Researches the niche. Builds the ICP. Maps Schwartz's 5 awareness levels. Pulls live language patterns from real Reddit / Trustpilot threads.

→ 01-market.json
02

offer-architect

Architects the value stack. Picks the pricing ladder (anchor, charm, decoy). Writes the guarantee. Builds the competitive teardown.

→ 02-offer.json
03

strategy-advisor

Picks the right funnel pattern: webinar, VSL, tripwire, quiz, challenge, SLO, or book. Outputs a Mermaid flow with stage-by-stage metrics.

→ 03-strategy.json
04

hook-engineer

15 hooks mapped to awareness levels. 3 headline ladders. Ad-ready, scroll-stopping, awareness-tuned.

→ 04-hooks.json
05

page-copywriter

3,500+ words across 9 sections. Hero, problem, agitation, solution, mechanism, proof, offer, guarantee, FAQ, final CTA. Ready to paste.

→ 05-page-copy.json
06

email-sequence-architect

21 emails across 4 sequences: welcome (5), nurture (7), sales (5), post-purchase (4). Subject + preview + body + delay + CTA.

→ 06-emails.json
07

vsl-scriptwriter

12 beats. Hook to close. 12–25 minute target runtime. Teleprompter-ready cadence.

→ 07-vsl.json
08

landing-design

Branded HTML + CSS landing page. Plus paste-ready prompts for GoHighLevel AI Studio, ClickFunnels AI, and Framer AI.

→ 08-design/*
09

funnel-orchestrator

Reads your intake — URL, PDF, plain notes, or all three mixed — and runs the entire pipeline. Streams progress as each agent finishes.

→ orchestrates 1–8
10

funnel-doctor

Post-launch. Paste your live URL + ad metrics. It WebFetches the page, diffs against the assets, walks the diagnostic tree, returns a punch list with realistic expected lifts.

→ 09-audit.json

What you actually type

Four commands. That's the whole interface.

/funnel-intake Build a complete funnel. Paste anything: URL, PDF, notes, mixed. Dashboard opens in 5 minutes.
/audit After launch. Paste live URL + metrics. Get a diagnostic punch list with expected lifts.
/funnel-list Show all your client funnels in one list, with quick links to each dashboard.
/funnel-help Reference card right inside Claude Code, anytime you forget anything.

Install — under 60 seconds

No terminal. No npm. No symlinks.

  1. 1

    Make sure Claude Code is installed

    Free at claude.com/claude-code. If you have it, skip.

  2. 2

    Open Claude Code in any folder

    For each new client, make a new folder so their assets stay isolated. Optional but recommended.

  3. 3

    Type these two commands in chat

    /plugin marketplace add naveends798/funnel-skills
/plugin install funnel-skills@funnel-skills
  4. 4

    Restart Claude Code once

    Close it completely, reopen. It re-reads the plugin on launch.

  5. 5

    Type /funnel-intake

    Paste anything you have about your client. Reply "go". Dashboard opens in 5 minutes.
