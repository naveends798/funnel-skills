what you actually type

/funnel-intake Build a funnel. Paste anything. Wait 5 minutes.

install · under 60 seconds

No terminal. No npm.
Two commands inside Claude Code.

1

Install Claude Code

Free at claude.com/claude-code. Skip if you already have it.

2

Open it in any folder

One folder per client keeps assets isolated.

3

Type these two commands

/plugin marketplace add naveends798/funnel-skills
/plugin install funnel-skills@funnel-skills
4

Restart Claude Code

It re-reads plugins on launch.

5

Type /funnel-intake

Paste client info. Reply "go". Dashboard opens in 5 minutes.
